# 微信小程序发布检查清单

## 代码配置

1. 确认 `project.config.json` 中的 `appid` 是微信公众平台的小程序 AppID：`wx4ec985e4083de341`。
2. 如果只有一个云开发环境，`app.js` 可以保持当前默认初始化；如果有多个环境，在 `wx.cloud.init` 里显式填写正式环境 ID。
3. 在微信开发者工具中选择 `miniprogram/` 目录导入项目。

## 云开发

1. 在微信开发者工具打开「云开发」，创建或选择正式环境。
2. 创建数据库集合：`study_data`。
3. 右键 `cloudfunctions/studyApi`，选择「上传并部署：云端安装依赖」。
4. 如果要导入当前本地学习数据，按 `IMPORT_LEGACY_DATA.md` 部署并调用 `importLegacyStudyData`。
5. 在开发者工具里预览，确认任务创建、完成、删除、标签、统计、本周页面都可用。
6. 确认导入成功后，可在云开发控制台删除 `importLegacyStudyData` 云函数，只保留 `studyApi`。

## 提交审核

1. 确认小程序已完成备案。
2. 服务类目建议选择与学习计划/效率工具相近的类目，例如「工具-效率」或后台当前可选的最贴近类目。
3. 版本描述可写：`学习任务记录、复习标签与学习统计 MVP`。
